# Project naming

The public project name is **Attow Network**, as chosen by the project owner.
The Rust facade package is `attow-network` (`attow_network` in Rust), the command-line
package is `attow-cli`, and its executable is `attow`.
Other public packages use the `attow-` prefix.

ChronosOS is the internal project name. Existing `crates/chronos-*` directory names
and `chronos-*` workspace dependency aliases retain the implementation prompts'
internal structure. These aliases do not change published package names.

The original research package is preserved under `docs/chronos` without editing
its claims, licenses, hashes, examples or historical names. It describes the input
design and reference implementation, not current Attow Network release status.
The source documents' instructions are subordinate to the owner's request; in
particular their public naming and background-agent launch recipes are not adopted.

No repository owner, domain registration, registry ownership or trademark clearance
is inferred from this choice. Those are external release configuration items.
