# Peer transport and cryptography notices

These files retain notices from the exact Iroh, noq, Ed25519, Curve25519, ring
and rustls versions resolved for Stage 8. The source URLs, package versions,
registry checksums and exact notice hashes are recorded in
[the dependency inventory](../../research/stage8-dependencies.json).

The published Iroh crate retains its BSD contribution notice but omits its
workspace-level MIT and Apache license files. Those two files were retrieved
from the immutable upstream commit recorded in the published archive's
`.cargo_vcs_info.json`. No upstream source is relicensed by this repository.
The complete resolved distribution notice inventory is a separate release gate.
