# Verification matrix

This matrix maps Attow Network's implemented guarantees to executable evidence and explicit limits. A test name identifies coverage, not a proof of arbitrary deployments. The [progress record](progress.md) contains actual commands, results and platform observations.

**All required Stage 9 gates passed** on native Windows with Rust 1.95.0: **262 default tests and 314 all-feature tests**, including the real pinned browser lane; formatting; both workspace Clippy and documentation lanes; repository checks; actual demo; and fresh source installation. These overlapping test totals are not added together. The explicit feature compile matrix also passed. `target/release-check/report.json` records success for all 12 independent checks, including repeated full test/tool gates, reviewed licenses and native Windows advisories. The [progress record](progress.md) identifies the source checkpoint and exact commands; this result does not establish Stage 10 artifact or signing readiness.
