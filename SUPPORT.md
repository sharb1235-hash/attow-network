# Support

Attow Network is an experimental 0.1.0 candidate. Native Windows x64 is the only candidate artifact target; actual verification is recorded in the release manifest and [progress](docs/progress.md). Configured CI lanes are not evidence that Linux or macOS has passed release qualification. No production SLA, backport commitment or stable migration contract is offered.

The owner-authorized public destination is `sharb1235-hash/attow-network`. Repository creation and its issue/private-reporting settings remain a setup item until verified. Once available, use its issue channel for ordinary questions and reproducible defects. Include revision, OS, Rust version, features, exact command, and a minimal non-sensitive owned fixture. Do not attach `.attow` directories, fence anchors, credentials or raw provider sessions. No support email or response-time promise has been configured.

For suspected vulnerabilities, follow the [private reporting guidance](SECURITY.md) instead of posting details publicly. For proposed contributions, read [CONTRIBUTING.md](CONTRIBUTING.md).

Start with [getting started](docs/getting-started.md), [operations](docs/operations.md) and [troubleshooting](docs/troubleshooting.md).
