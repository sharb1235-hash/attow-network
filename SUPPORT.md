# Support

Attow Network currently provides a development workspace, with functionality added through sequential implementation stages. Consult the [README](README.md) and [progress record](docs/progress.md) before relying on a feature.

For ordinary questions or defects, use the project's configured repository discussion or issue channel when available. Include the revision, operating system, Rust version, enabled features, exact command and a small reproduction using non-sensitive fixture data. No public repository URL, support email or response-time commitment has been configured here.

For suspected vulnerabilities, follow the [private reporting guidance](SECURITY.md) instead of posting details publicly. For proposed contributions, read [CONTRIBUTING.md](CONTRIBUTING.md).
